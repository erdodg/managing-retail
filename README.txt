Managing Retail Alfamart - public live deck (Group 3)

Open index.html from any public web host. No login needed for anyone.
- Presenter: open  <your-site>/#host  once on the presenting laptop (enables Reveal/Reset buttons), then use the deck.
- Audience: scan the QR code on the slides (it points to <your-site>/#ikut automatically).
- Live votes, quiz answers, emoji and comments travel through the public ntfy.sh service.
  Ask the audience to use mobile data if many people share one Wi-Fi network.
- Before the talk: open ⋯ menu -> "Reset all votes, quizzes and reactions" to clear test answers.

Fast hosting options (free):
1) Netlify Drop: go to app.netlify.com/drop, drag this whole folder in, copy the URL it gives you.
2) GitHub Pages: new public repository -> upload all files -> Settings -> Pages -> Deploy from branch (main, /root).
